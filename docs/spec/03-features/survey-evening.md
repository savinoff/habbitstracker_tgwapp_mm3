# Feature: Вечерний опрос (survey-evening)

> **spec_version:** 0.1.0
> **status:** draft
> **last_updated:** 2026-07-30

## q1. Назначение

Фиксация дневных привычек и эмоционального состояния. Заполняется один раз в день, **в окне с 18:00 до 23:59 локального времени пользователя**.

## q2. Поля формы

| # | Поле | Тип | Обяз. | Ограничения | UI-контрол |
|---|---|---|---|---|---|
| 1 | `smoked_count` | int | да | 0–50 | Степпер −/+ |
| 2 | `ate_sugar` | enum | да | `yes` / `no` / `unsure` | 3 кнопки-чипа |
| 3 | `did_sport` | bool | да | true / false | 2 кнопки-чипа |
| 4 | `sport_note` | string | нет | ≤ 100 символов | Textarea (видна, только если `did_sport=true`) |
| 5 | `mood_evening` | int | да | 1–5 | 5 эмодзи-кнопок (😞 😕 😐 🙂 😄) |
| 6 | `best_memory` | string | нет | ≤ 300 символов, trim | Textarea |

## q3. Поведение

- Сохранение = POST `/api/surveys/evening` с телом `{date, smoked_count, ate_sugar, did_sport, sport_note?, mood_evening, best_memory?}`.
- `date` — локальная дата пользователя в формате `YYYY-MM-DD`.
- **Идемпотентность:** повторный POST за ту же локальную дату перезаписывает запись (аналогично morning).
- **Валидация:** см. `05-api.md#q4`.

## q4. UX-детали

- В вечернем окне Mini App сразу открывает вечернюю форму.
- Если заполнена — показ с кнопкой «Редактировать».
- Длинные тексты (`sport_note`, `best_memory`) — `Textarea` с автоматическим ростом, без жёсткого `rows=`.
- После сохранения — экран подтверждения, `MainButton.text = "Вечер записан ✓"`.
- **Догоняющее напоминание:** если через 60 минут после основного вечернего напоминания записи ещё нет — бот шлёт одно мягкое напоминание. Дальше — тишина до следующего дня (см. `03-features/reminders.md#q5`).
