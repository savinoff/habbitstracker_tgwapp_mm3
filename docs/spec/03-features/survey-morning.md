# Feature: Утренний опрос (survey-morning)

> **spec_version:** 0.1.0
> **status:** draft
> **last_updated:** 2026-07-30

## q1. Назначение

Фиксация сна и утреннего настроя. Заполняется один раз в день, **в окне с 04:00 до 12:00 локального времени пользователя** (см. `03-features/reminders.md#q3`).

## q2. Поля формы

| # | Поле | Тип | Обяз. | Ограничения | UI-контрол |
|---|---|---|---|---|---|
| 1 | `sleep_hours` | float | да | 0–14, шаг 0.5 | Степпер −/+ или слайдер |
| 2 | `sleep_quality` | int | да | 1–5 | 5 эмодзи-кнопок (😴 😐 🙂 😊 🤩) |
| 3 | `mood_morning` | int | да | 1–5 | 5 эмодзи-кнопок (😞 😕 😐 🙂 😄) |
| 4 | `intention` | string | нет | ≤ 200 символов, trim | Textarea |

## q3. Поведение

- Сохранение = POST `/api/surveys/morning` с телом `{date, sleep_hours, sleep_quality, mood_morning, intention?}`.
- `date` — локальная дата пользователя в формате `YYYY-MM-DD`. Сервер пересчитывает в UTC по timezone пользователя и сохраняет абсолютный момент `created_at`.
- **Идемпотентность:** повторный POST за ту же локальную дату **перезаписывает** существующую утреннюю запись. Это позволяет исправлять ошибки, не плодя дубли.
- **Валидация:** все поля проверяются на сервере (см. `05-api.md#q3`). Клиент тоже валидирует для UX, но нельзя полагаться только на клиент.

## q4. UX-детали

- При открытии Mini App в утреннем окне — пользователь сразу попадает на форму утреннего опроса.
- Если форма уже заполнена сегодня — пользователь видит свои ответы и кнопку «Редактировать».
- После сохранения — экран подтверждения с анимацией (Telegram `MainButton.text = "Утро записано ✓"`).
- Кнопка «Назад» в Telegram (`BackButton`) — закрывает Mini App.
