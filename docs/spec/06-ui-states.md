# 06. UI States

> **spec_version:** 0.1.0
> **status:** draft
> **last_updated:** 2026-07-30

UI — single-page application с **нижней таб-баром** (3 вкладки: Главная / История / Настройки). Внутри вкладки состояния переключаются без смены URL (Telegram WebApp не использует адресную строку).

Цветовая схема — берётся из Telegram theme params (`tg-theme-bg-color`, `tg-theme-text-color`, `tg-theme-button-color`). Минимум своих цветов, чтобы нативно вписываться.

---

## q1. Карта экранов

```
[Главная]                    [История]                  [Настройки]
 ├─ Нет записи утро          ├─ Список дней              ├─ Форма настроек
 │   → пустая утро-форма     │   → раскрытая карточка    │   → подтверждение
 ├─ Утро заполнено               (US-09 edit)
 │   → превью + Edit
 ├─ Нет записи вечер
 │   → пустая вечер-форма
 ├─ Вечер заполнен
 │   → превью + Edit
 └─ Loading / Error
```

## q2. Главный экран — логика отображения

На входе бэкенд отдаёт: `morning_for_today`, `evening_for_today`, `tz`, `now_local`.

Правила:
- Если `now_local` в утреннем окне (04:00–12:00) и `morning_for_today` пуст → показать утреннюю форму.
- Иначе если `morning_for_today` заполнен → показать блок-превью с кнопкой «Изменить».
- Аналогично для вечера (18:00–23:59).
- Если сейчас вне обоих окон — показать последнюю запись с предложением заглянуть в историю.

## q3. Экран «Утренняя форма»

Поля (см. `03-features/survey-morning.md#q2`):
- `sleep_hours` — слайдер 0..14, шаг 0.5, текущее значение в центре.
- `sleep_quality` — горизонтальный ряд из 5 эмодзи-кнопок; выбранная крупнее.
- `mood_morning` — то же.
- `intention` — textarea, 2 строки, плейсхолдер «Что хочешь сделать сегодня?».

Снизу — `MainButton` Telegram с текстом «Сохранить утро». По нажатию — POST `/api/surveys/morning`.

Сверху слева — `BackButton` Telegram закрывает Mini App.

## q4. Экран «Вечерняя форма»

Аналогично q3, но:
- `smoked_count` — степпер с кнопками − / N / + (макс 50).
- `ate_sugar` — три чипа: «Да / Нет / Не помню».
- `did_sport` — два чипа: «Да / Нет». Если «Да» — под полем появляется `sport_note` (textarea).
- `mood_evening` — 5 эмодзи.
- `best_memory` — textarea, 3 строки, плейсхолдер «Что хорошего случилось сегодня?».

`MainButton.text = "Сохранить вечер"`.

## q5. Экран «История»

Верх: сегментированный контрол «7 дней / 30 дней / Всё».

Список карточек (см. `03-features/history.md#q4`):
- Дата — заголовок карточки.
- Под ней — две строки превью: «Утро: …» и «Вечер: …» с иконкой статуса.
- Тап — раскрытие. Повторный тап (или «Свернуть») — закрытие.

Пустое состояние (если в окне вообще нет дней, т.е. пользователь только установил) — большая надпись «Здесь будет твоя история» + совет «Заполни первый опрос».

## q6. Экран «Настройки»

Поля (см. `03-features/settings.md#q2`):
- `morning_hour_minute` — time-input (HTML5 `<input type="time">`).
- `evening_hour_minute` — то же.
- `timezone` — `<select>` с фиксированным списком (см. `03-features/settings.md#q4`).
- Кнопка «Сбросить на дефолтные» (только время, не TZ).
- Кнопка «Сохранить» (`MainButton`).

## q7. Состояния загрузки и ошибок

| Состояние | Что показываем |
|---|---|
| Loading (любой запрос) | Локальный спиннер на месте будущего контента, не full-screen |
| 401 | «Сессия истекла. Закрой и открой Mini App заново.» + кнопка «Закрыть» |
| 400 (валидация) | Красная подсветка проблемного поля, текст ошибки под ним |
| 500 / network | «Не получилось. Попробуй ещё раз.» + кнопка «Повторить» |
| 404 | Скрываем элемент (запись не найдена в истории — крайне редко) |

## q8. Telegram-специфика

- `tg.MainButton` — для всех «Сохранить» / «Сохранить утро» / «Сохранить вечер» / «Сохранить настройки».
- `tg.BackButton` — закрытие Mini App (на главной); на других экранах — возврат к предыдущему состоянию внутри SPA (без закрытия).
- `tg.HapticFeedback.impactOccurred('light')` — на тап эмодзи-кнопок.
- `tg.HapticFeedback.notificationOccurred('success')` — после успешного сохранения.
- `tg.expand()` — вызвать сразу на старте, чтобы Mini App занял весь экран.
- Цвета — из `tg.themeParams`, fallback'и в CSS-переменных.
